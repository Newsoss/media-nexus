# MediaNexus

Курсовой проект: сайт для хранения изображений и заметок со связями между ними.
Визуальный ориентир рабочего поля — [Milanote](https://milanote.com/).
Граф связей основан на идее Obsidian. Код и оформление реализованы самостоятельно.

## Возможности

- Создание, просмотр, редактирование и удаление карточек. Удалить карточку можно кнопкой корзины на доске или в окне просмотра; перед удалением появляется подтверждение.
- Изображения с компьютера (до 4 МБ) или по прямой ссылке; текстовые заметки и теги.
- Карточки автоматически размещаются в сетке. Сортировка: сначала новые, сначала старые или по названию А–Я.
- Создание, переименование и удаление тем. Новую тему можно добавить из бокового меню или прямо в форме карточки; в форме она сразу отмечается для этой карточки.
- Одна карточка может принадлежать нескольким темам. Они выбираются флажками в форме.
- «Все материалы» показывает все карточки, включая карточки без выбранных тем.
- При удалении темы сохраняются карточки, их связи и назначения в других темах.
- На рабочей доске нет линий и счётчиков связей. Визуальные связи отображаются в разделе «Граф».
- Связи редактируются в форме карточки; связанные материалы можно открывать из окна просмотра.
- Темы фильтруют рабочее поле и граф. В графе выбранной темы видны связи между её карточками.

## Поиск

Поле в верхней панели ищет по части названия, заметки или тега без учёта регистра.
Поиск ограничен выбранной темой и одинаково фильтрует доску и граф.
Чтобы снова увидеть все карточки, очистите поле или нажмите Escape.

## Демонстрация

Для добавления готового набора материалов из корня проекта выполните:

```sh
npm run demo --prefix backend
```

Добавятся две темы и шесть связанных карточек о подготовке сайта студенческого фестиваля.
Повторный запуск не создаёт копии и не восстанавливает удалённые демонстрационные материалы.
Существующие карточки сохраняются. Полный сценарий показа на 5–7 минут — в [docs/DEMO.md](docs/DEMO.md).

## Примеры

При первом запуске новой версии один раз добавляются темы «Веб-дизайн» и «Разработка»
и две заметки с тегом «Пример»:

- «Главная страница — референсы» — в теме «Веб-дизайн».
- «Компоненты карточки» — одновременно в темах «Веб-дизайн» и «Разработка».

Эти заметки связаны между собой для демонстрации графа.
Исходные демонстрационные фотографии также распределяются по темам,
если для них ещё не было выбрано назначение. Остальные материалы сохраняются.
Примеры можно редактировать и удалять; после перезапуска они не создаются заново.
Назначения из прежних тематических досок автоматически переносятся в новую схему.

## Запуск

Нужна версия Node.js, совместимая с Vite 8 и better-sqlite3 13, например Node.js 24.
В корне проекта установить зависимости, затем запустить сервер:

```sh
npm install
cd backend
npm install
npm start
```

В другом терминале из корня проекта:

```sh
npm run dev
```

Открыть адрес Vite, обычно http://localhost:5173.
API по умолчанию работает на порту 5000, база находится в `backend/media_nexus.db`.
После обновления серверного кода нужно перезапустить `npm start`.
Миграции базы выполняются автоматически.

Адрес API можно задать через `VITE_API_URL` в корневом `.env`,
например `VITE_API_URL=http://localhost:5000/api`.
Сервер поддерживает переменные `PORT` и `DATABASE_PATH` для другой базы или порта.

## Изображения

JPG, PNG, WebP, GIF и AVIF до 4 МБ сохраняются в SQLite вместе с карточкой.
Для ссылки нужна именно картинка, а не страница сайта. Если она перестанет работать,
интерфейс покажет сообщение; файл можно заменить при редактировании.
Четыре фотографии исходных карточек сохранены в `public/images`
из ранее использованных ссылок Unsplash. Новая карточка без изображения — текстовая заметка.

## Рабочее поле

Карточки располагаются автоматически, перетаскивание отключено.
Список в шапке доски меняет порядок карточек: по умолчанию сначала новые,
также доступны сначала старые и сортировка по названию.
Сортировка работает вместе с поиском и фильтром тем.
Удаление карточки убирает её из всех тем и удаляет её связи в графе.

## Проверка

```sh
npm run lint
npm run build
cd backend
npm test
```

Тесты работают с отдельными базами и проверяют миграции, редактирование карточек,
изображения, связи, положение на доске, назначение нескольких тем и сохранение данных.
